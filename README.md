# Mid TN VBC — Tryout Manager & Volleyball Skill Tracker

Comprehensive volleyball tryout management system with real-time station scoring, depth chart ranking, drag-and-drop team building, offer tracking, and AI-powered rule assistant ("VOLLEY AI").

## Initial User Review Feedback & Resolved Features

- **Walk-ups & Testing Flow**: Walk-ups can register via QR code on mobile or desk "+ Add Walkup", automatically generating tryout numbers and entering Station 1 (Physical) and Station 2 (Agility) testing.
- **Station Operations**:
  - Station 1: Height, Reach, Vertical.
  - Station 2: Agility Shuttle Run with integrated digital stopwatch timer.
  - Check-in & Search: Drill scoring integrated directly into check-in and search flows.
- **Depth Chart & Team Builder Integration**:
  - Depth Chart ranks athletes by primary position match first (descending total score) followed by secondary position match, displaying secondary position tags.
  - Team Builder includes full depth chart pool sorting, primary/secondary visibility, tryout note icons (📝), restriction warnings (⚠️), and team '🔒 Finalize' locking.
- **Athlete Profile & Call Log**: Dedicated notes section on every athlete profile card for tryout notes, phone calls, and team restrictions.
- **Offer Process**: Supports sending team offers as well as re-sending individual offers to replacement candidates if an athlete declines. Accepted players lock automatically.
- **Check-in Editing**: Ability to edit phone, email, and positions upon check-in or via the registration table.
- **PDF & CSV Exports**: Comprehensive CSV export and styled print-to-PDF layout for finalized rosters and registration data.
