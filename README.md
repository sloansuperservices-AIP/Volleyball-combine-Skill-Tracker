# Mid TN VBC — Volleyball Tryout Manager & Skill Tracker

Skill tracking, tryout management, depth charts, team building, and automated offer communications for Mid TN Volleyball Club.

## The Tandem Pipeline
This project is maintained through a synchronized, high-efficiency pipeline:
- **GitHub**: Source of truth for version control, code hosting, and repository stability.
- **Google AI Studio**: Strategic planning, architectural design, requirements analysis, and prompt strategy.
- **Jules AI**: Autonomous coding agent executing sandbox implementations, testing, bug fixes, and continuous verification.

## Tryout Manager Key Features
- **Walk-up Registration & Check-In**: Self-service QR registration (`?mode=walkup`) and desk sign-in with instant phone/email confirmation.
- **Streamlined Stations**:
  - **Station 1**: Reach & Vertical (Height, Reach, Vertical).
  - **Station 2**: Agility timing (Shuttle Run stopwatch integration).
  - **Drill Score**: Integrated into check-in and athlete profiles.
- **Depth Chart**: Ranks athletes by position category, sorting primary position matches first by total score descending, with secondary position badges.
- **Team Builder**: Drag-and-drop roster assembly, "Show All" pool visibility, notes/restriction icons (`📝`, `⚠️`), and team finalization locking (`🔒`).
- **Individual Roster Offers**: Custom individual offer letter generation with email/mailto delivery, resend capabilities for declined replacement spots, and acceptance profile locking.
- **Data Export & Reporting**: PDF print layouts and 21-field CSV spreadsheet exports.
