# Volleyball-combine-Skill-Tracker
Skill tracking for Volleyball using vision and leaderboard. 

## The Collaborative Tandem (The Tandem Pipeline)
This project is maintained through a synchronized, collaborative development pipeline involving three primary entities:

1. **GitHub**: The single source of truth for version control, issue tracking, and repository releases.
2. **Google AI Studio**: Strategic planning, architectural guidance, rules analysis, and feature strategy definition.
3. **Jules AI (Coding Agent)**: Autonomous implementation, bug fixes, automated syntax validation, sandbox testing, and pre-commit verification.

### Workflow Cycle
- **Strategic Direction**: Requirements and feedback from end users are analyzed in Google AI Studio to establish clear architectural goals.
- **Implementation & Refinement**: Jules AI executes code changes directly in the sandbox, performing static syntax checks and functional testing.
- **Versioned Stability**: Changes are pushed to GitHub to maintain versioned stability and deploy to GitHub Pages.
