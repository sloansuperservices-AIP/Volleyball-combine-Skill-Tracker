# Volleyball-combine-Skill-Tracker
Skill tracking for Volleyball using vision and leaderboard. 

## The Collaborative Tandem Pipeline
This project is maintained through a high-efficiency collaborative pipeline involving three primary entities:

1. **GitHub**: Source of truth for version control, code review, and repository management.
2. **Google AI Studio**: Strategic planning, architectural design, prompt engineering, and logic prototyping.
3. **Jules AI**: Autonomous implementation, testing, sandbox verification, and continuous refinement.

### How the Pipeline Works:
- **Strategy & Prototyping**: Requirements and feedback from end-users are analyzed in Google AI Studio to establish clear technical specifications.
- **Implementation & Verification**: Jules AI executes code changes directly in the sandbox, runs syntax/unit tests, and verifies UI workflows using automated browser testing (Playwright).
- **Deployment & Versioning**: Verified code changes are committed and pushed to GitHub for review and deployment to GitHub Pages.
